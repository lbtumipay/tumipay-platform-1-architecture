# TumiPay Architecture AI Skills

These Skills define specialized responsibilities for AI agents working on the platform architecture repository.

## Execution groups

### Foundation
- repository-discovery
- requirements-baseline
- legacy-analysis
- architecture-modeling
- diagramming
- architecture-review
- architecture-traceability

### Domain and platform modeling
- capability-modeling
- domain-modeling
- bounded-context-design
- context-mapping
- event-modeling
- financial-modeling
- component-architecture

### Technical architecture
- integration-architecture
- api-design
- event-contracts
- data-architecture
- security-architecture
- reliability-architecture
- observability-architecture
- infrastructure-architecture

### Governance and documentation
- architecture-decisions
- architecture-documentation

The Skills are deliberately specialized. They must collaborate through repository artifacts and must not duplicate the responsibilities of other Skills.
